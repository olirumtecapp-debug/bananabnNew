# Mico Mania

Objetivo: - Reproduzir as regras tradicionais do jogo Mico (Old Maid). -

Interface moderna, intuitiva e totalmente em português.

Funcionalidades: - Jogador vs IA. - Multiplayer local pela mesma rede

Wi-Fi (LAN) tipo conectar em sala com identificador. - Multiplayer por Bluetooth. - Criar sala e entrar em

sala. - Reconexão quando possível. - Animações suaves de distribuição e

retirada de cartas.

Regras: - Baralho padrão com um Mico (carta sem par). - Remoção

automática dos pares. - Jogadores retiram uma carta aleatória do

adversário. - Vence quem termina sem o Mico. - Tutorial explicando as

regras.

Layout: - Interface responsiva. - Adaptar automaticamente a celulares e

tablets. - Utilizar layouts responsivos, ConstraintLayout/Jetpack

Compose e dimensões relativas. - Suportar modo retrato e paisagem. -

Respeitar áreas de câmera/notch.

Monetização: - Integrar Google AdMob. - Banner apenas no menu

principal. - Interstitial somente ao final de partidas. - Nunca

interromper a jogabilidade.

Compras: - Integrar Google Play Billing. - Compra única “Remover

anúncios”. - Valor sugerido: R$ 4,99. - Após a compra, desativar

permanentemente todos os anúncios.

Outros: - Sons, vibração opcional, estatísticas, ranking local, temas

claro e escuro. - Código organizado, comentado e preparado para futuras

atualizações.
